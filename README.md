### 💡 Inspirations & Philosophy

> "Automate everything, monitor continuously, and build resilient infrastructure."

* ⚙️ **Infrastructure as Code & Automation:** Transforming manual configurations into repeatable, version-controlled code (Terraform, Ansible).
* 📊 **Observability & Reliability:** Ensuring high availability and deep system visibility through proactive monitoring (Prometheus, Grafana).
* 🔒 **Security & Modern Operations:** Integrating security early in the delivery pipeline (Vault, Docker, Kubernetes) and optimizing IT service management (GLPI).
* 📚 **Continuous Improvement:** Constant learning, hands-on experimentation, and leveraging modern DevOps practices to bridge the gap between development and operations.
